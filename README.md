# Hộp Chơi — Galaxy 3D Toy

Chơi tại https://acquaday14-arch.github.io/hop-choi-web/

Kho này chỉ chứa bản web đã biên dịch; mã nguồn được giữ trong kho riêng.

Online: chia sẻ mã phòng; chủ phòng cần giữ tab mở. Phòng chơi dùng Firebase Realtime Database với phiên khách ẩn danh; không cần WebRTC/TURN. Chủ phòng vẫn giữ engine trong tab. Tải lại hoặc đóng tab chủ phòng sẽ kết thúc phòng. Chơi với máy không cần server phòng.
